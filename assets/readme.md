# Assets

В этой папке хранятся **статические ресурсы**, необходимые для работы генератора.

В отличие от папки `storage` (где лежат пользовательские голоса и модели), содержимое `assets` представляет собой
готовый набор (Asset Pack).

## Структура

### 1. `ambient/`

Фоновые звуки (эмбиенты), которые играют на заднем плане сцен.

* **Формат:** `.mp3` (рекомендуется 128kbps).
* **Требования:** Файлы должны быть **зациклены** (без тишины в начале и конце), чтобы играть бесшовно.
* **Нормализация:** Рекомендуемая громкость **-25 dBFS** (чтобы не перебивать голос).

> В `tools/` есть `import_audio.py`, который может помочь с этим

### 2. `emotion_references/`

Эталонные аудиофайлы для передачи специфических эмоций (смех, шепот, крик), если модель поддерживает Reference Audio.
Некоторые модели поддерживают генерацию эмоций по промпту, в таком случае референсы не нужны.

## Конфигурационные файлы (JSON)

Эти файлы служат "библиотекой", по которой LLM ориентируется в доступных ресурсах.

### `ambient_library.json`

Реестр доступных эмбиентов. LLM выбирает ID из этого списка на основе контекста сцены.

* **Ключ (`id`):** Имя файла в папке `ambient/` (без расширения).
* **Описание:** Текстовое описание для LLM (например: *"Шумная таверна, звон посуды"*).

### `sfx_library.json`

Реестр звуковых эффектов (One-shot SFX), таких как удары, шаги, двери.

* **Ключ:** ID эффекта.
* **Значение:** Описание звука.

### `pronunciation_dictionary.json`

Словарь для исправления произношения в TTS.

* **Пример:** `"Маомао": "МаомАо"` (помогает ставить ударения).

> У разных моделей ударение делается в разном формате. Какие-то из них ставят ударение на заглавные буквы, а какие-то на
> буквы перед которыми стоит "+". Почитайте документацию.

### `emotion_reference_library.json`

Список поддерживаемых эмоций и стилей речи для валидации сценария. Если модель поддерживает нативно эмоции (просто можно
добавить в промпт), то они будут и в озвучке. Какие-то сложные эмоции скорее всего не будут работать.

* `narrator_styles`: Стили рассказчика (neutral, slow, mysterious...).
* `character_emotions`: Эмоции персонажей.

> У рассказчика лучше не добавлять каких-то ярких эмоций, будет не совсем понятно кто вообще это говорит. А у персонажей
> в целом ограничений нет

### `comfy_workflow.json`

Экспортированный Workflow из ComfyUI в формате API.

* Используется для генерации иллюстраций.
* Содержит узлы (Nodes) и связи для пайплайна Image Gen.

> Нужно зайти в `Dev Mode` в ComfyUI и скачать пайплайн в формате api

## Как добавить новый ресурс?

1. **Аудио (Эмбиент):**
    1. Обработайте файл (используйте `import_audio.py`).
    2. Положите файл в `ambient/` (например `cave_wind.mp3`).
    3. Добавьте запись в `ambient_library.json`:
    ```
    {
    "id": "cave_wind",
    "description": "Жуткий вой ветра в пещере, капающая вода, эхо.",
    "tags": ["пещера", "ветер", "страх"]
    }
    ```
2. **Словарь:**
    1. Просто добавьте пару "Слово": "Замена" в `pronunciation_dictionary.json`.
