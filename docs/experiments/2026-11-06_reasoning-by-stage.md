# Reasoning по этапам пайплайна сценария

**Дата:** 2026-11-06
**Ветка:** `experiment/deepseek-deepinfra`
**Модель:** `deepseek/deepseek-v4.1-flash-1017`, провайдер DeepInfra `fp8` (без flex)
**Данные:** «Монолог фармацевта» (LN), том 1, главы 1 и 3. Текст глав взят из `output/kusuriya-no-hitorigoto/project.db`, то есть тот же, на котором раньше работала MiMo.
**Сырые логи:** `logs/experiments/` (`fix1-3.log` — базовая линия, `nr1-2.log` — эксперимент, скрипт `stage_run.py`)

## Контекст

- После перехода на DeepSeek выяснилось, что модель по умолчанию рассуждает (reasoning), и это ~80% стоимости главы. Статичная часть промптов — около 3%, поэтому сжимать промпты ради денег смысла нет.
- Самый дорогой вызов на главу — `sound_design`: 11–14k токенов размышлений, чтобы выбрать ambient из 8 треков и SFX из 24.
- `effort: low` на этапе сценария почти не уменьшил reasoning (5–10k против 6–8k), поэтому здесь сравнивали только `none` и вариант по умолчанию.

## Что сравнивали

| | Базовая линия (fix1–3) | Эксперимент (nr1–2) |
|---|---|---|
| `scenario_generation` | по умолчанию | по умолчанию |
| `sound_design` | по умолчанию | `none` |
| `emotion_analysis` | по умолчанию | `none` |
| Повторов | 3 | 2 |

Перед каждым прогоном для глав 1 и 3 очищались `scenarioentry` и `chaptercache`. Персонажи и саммари одинаковые во всех копиях.

### Качество

- **Ambient:** разницы нет. Почти везде `palace_hall_quiet`. Базовая линия сама нестабильна: в fix1 у главы 3 семь реплик `city_street_day`, в остальных прогонах их нет.
- **Эмоции и теги `tts_text`:** тот же разброс в обоих вариантах (глава 1: 3–5 тегированных реплик, глава 3: 18–30).
- **SFX без reasoning хуже.** Появились притянутые звуки:
  - `pour_liquid` на «наложница пила алкоголь из чашки», в обоих повторах. Промпт прямо запрещает такие ассоциации на этом же звуке.
  - `laugh_crowd` на «Джинши... начал смеяться»: смеётся один человек.
  - В базовой линии все SFX уместные (шаги, стук и открытие двери, шелест бумаги).

### Проверка покрытия текста

Все 4 чанка в nr1–2 прошли с первой попытки (покрытие 95–100%), повтор не понадобился. Ветка с повтором на живой модели пока не проверена.

## Решение

- `emotion_analysis` → `none` (включено в `output/system.db`: `openrouter_reasoning_by_stage = {"emotion_analysis": "none"}`).
- `sound_design` остаётся с reasoning по умолчанию: без него страдает точность SFX.

## Что дальше

- Разделить sound design: ambient оставить LLM без reasoning (там она справляется), SFX определять словарём лемм по явным действиям в тексте («налить», а не «пить»). Сравнить с базовой линией на тех же главах.
- Повторов мало (2–3), выводы про качество качественные, не статистические. На целом томе картина может отличаться.
