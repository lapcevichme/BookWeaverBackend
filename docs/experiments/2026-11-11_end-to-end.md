# Сквозной прогон после миграции на DeepSeek

**Дата:** 2026-11-11
**Ветка:** `experiment/deepseek-deepinfra` (перед слиянием в `main`)
**Конфигурация:** умолчания из `config.py` (`d07ebe8`): DeepSeek V4.1 Flash, DeepInfra fp8, эмоции без reasoning, таймауты по этапам.
**Данные:** «Монолог фармацевта» (LN), том 1, главы 0–3, чистая копия без пересказов, персонажей и сценариев (`kusuriya-no-hitorigoto__e2e`).
**Сырые данные:** `logs/experiments/e2e/` (`e2e.log`, скрипт `e2e_run.py`)

Запуск — `Application.run_full_cycle(book, max_chapters=4)`, как его вызывает сервер: пересказы → персонажи → сценарий (текст + звук + эмоции). TTS не входит в цикл и здесь не запускался (нет GPU).

## Найдено

- В 46 из 147 реплик `tts_text` содержит теги `<|pause|>`/`<|sigh|>`/… Qwen3-TTS читает их вслух («Поза», «Сих»), а CosyVoice 3 их тоже не знает (его теги — `[breath]`, `[laughter]`, `[sigh]`…). Починка — в работе над голосами: `<|pause|>` → перенос строки (~0.4 с паузы), остальные теги убрать.
