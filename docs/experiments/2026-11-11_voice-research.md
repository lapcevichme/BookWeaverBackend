# Голоса: исследование Qwen3-TTS, VoiceDesign и план кастинга

**Даты:** 2026-11-10 – 2026-11-11
**Сырые данные:** `logs/experiments/voicedesign/` (wav, `timings.json`, скрипты `vd_run.py`, `checks_base.py`, `checks_design.py`, `checks_pauses.py`)
**Окружение:** CPU (AMD Phoenix3, 16 потоков, без NVIDIA), отдельный venv `~/.venvs/qwen-tts-cpu` (torch 2.5.1+cpu, qwen-tts 0.1.1). Модели в `~/.cache/huggingface`: `Qwen3-TTS-12Hz-1.7B-VoiceDesign` (4.3 ГБ), `0.6B-Base`.

## Как голоса устроены сейчас (до исследования)

- Голос назначается вручную: `character_voices` в конфиге книги («Капитанская дочка» — 14, lnln — 50, Кусурия — 2) или `voice_base` из UI (id папки `storage/voices/<id>/reference.*`).
- LLM писала теги («young male, calm») в тот же `voice_base`; ни в одном из 10 проектов это не совпало с папкой голоса, TTS молча брал рассказчика. Разделено в коммите «separate voice profile from assigned voice»: `voice_base` = id голоса, `voice_profile` = описание от LLM.
- `tools/voice_picker.py` ищет готовые голоса в общей библиотеке ElevenLabs и не подключен к БД персонажей (в `__main__` демо-задачи).
- TTS — Qwen3-TTS (коммит `c99a0da`, 2026-10-19, без описания причины). `CosyVoiceClient` — псевдоним `QwenTTSClient`; старый клиент в `git show c99a0da^:services/cosyvoice_client.py`. Локально есть `../CosyVoice` с `Fun-CosyVoice3-0.5B` и русскими пробами от 2026-01-04.

## Факты о Qwen3-TTS (проверено по коду пакета и README)

| Модель | Умеет | Instruct |
|---|---|---|
| `1.7B-CustomVoice` | 9 готовых голосов + стиль | да |
| `1.7B-VoiceDesign` | голос по описанию | да |
| `1.7B/0.6B-Base` | клонирование по 3-секундному образцу | **нет** |

- `generate_voice_clone` не строит `instruct_ids`; `**kwargs` идут в `generate()` трансформеров (параметры сэмплирования). Эмоции на клоне — только из смысла текста.
- **Тегов нет**: в токенизаторе 33 служебных токена, все структурные. README, техотчет (arXiv 2601.15621) — ни слова о паузах/смехе.
- **Официальный рецепт «Voice Design then Clone»** (README пакета, раздел на строке 316 METADATA): VoiceDesign один раз делает референс → `create_voice_clone_prompt` → `generate_voice_clone` для всех реплик. Ровно наш будущий кастинг.
- `VoiceClonePromptItem` = `ref_spk_embedding` (вектор диктора) + `ref_code` (референс в токенах кодека) + `ref_text`. Режимы: ICL (все три, лучше) и `x_vector_only_mode` (только вектор). Долговременное хранение — `reference.wav` + `reference.txt` (коды привязаны к версии токенизатора); промпт — кэш (сервер уже держит его в памяти по `voice_id`).

## Замеры

### VoiceDesign на CPU, 4 персонажа Кусурии по `voice_profile`

| Голос | Профиль | Генерация | F0 медиана | Оценка автора |
|---|---|---|---|---|
| Джинши | adult male, calm, thoughtful, soft-spoken, analytical | 125 с на 4.9 с (RTF 26) | 120 Гц | «офигенно» |
| Император | adult male, authoritative, calm, confident, commanding | 102 с на 4.2 с | 112 Гц | хорошо |
| Рифа | adult female, sharp, furious, commanding, emotional | 114 с на 5.1 с | 433 Гц | сомнительно: базовому голосу не нужны эмоции |
| Маомао | young female, calm, practical, observant, slightly weary | 132 с на 6.0 с | 348 Гц | плохо: детский голос, а ей 17 |

Норма речи: взрослые женщины ~165–255 Гц, дети ~250–400.

**Маомао v2** («Female, 17 years old, young adult woman, mezzo-soprano range, medium-low pitch, … not childlike, not high-pitched», нейтральная фраза): F0 360 Гц (pyin) / 336 Гц (yin) — **не помогло**. Похоже, VoiceDesign завышает женские голоса в целом. Не прослушано.

**Джинши «болен»** (тот же профиль + «hoarse and raspy voice, sore throat, sick and tired»): F0 120 → 104 Гц. Тот же ли человек — не прослушано.

### Эмбеддинги диктора — гипотеза опровергнута

Косинусное сходство сырых `ref_spk_embedding`: Джинши–Император 0.98, Джинши–Джинши_болен 0.97, Маомао–Рифа 0.98, мужские–женские 0.88–0.89. **Различает только пол**; для проверки различимости голосов в составе в таком виде не годится.

### Теги в тексте (клон Джинши, 0.6B-Base, распознано Whisper small)

- `Ты опять пришла сюда ночью. Зачем?` → то же.
- `… ночью. <|pause|> Зачем? <|sigh|>` → «… ночью. **Поза** зачем? **Сих.**»

**Qwen читает теги вслух.** Сквозной прогон (`2026-11-11_end-to-end.md`): теги есть в 46 из 147 реплик. Кроме того, это не теги CosyVoice 3 (его токенизатор знает `[breath]`, `[quick_breath]`, `[laughter]`, `<laughter>…</laughter>`, `[sigh]`, `[cough]`, `<strong>…</strong>`…), а `<|pause|>` и др. появились в промпте эмоций 2026-03-21 (`f6fcc7d`) — то есть, вероятно, не работали и на CosyVoice.

### Паузы пунктуацией (клон Джинши, по 2 попытки)

| Разделитель | Самая длинная пауза |
|---|---|
| `.` | 0.04 с |
| `—` | 0.05 с |
| `...` | 0.10 с |
| `... ...` | 0.21 с (нестабильно) |
| `\n\n` | **0.42 с** (0.38, 0.45) |

`preprocess_text_for_tts` переносы строк не вырезает.

## Решения автора

- **Одна модель (Qwen3-TTS) и для дизайна, и для озвучки** — проще и меньше проблем. Цена: нет instruct на клоне, нет тегов; смех/вздохи — только SFX.
- **Голос — постобработка («кастинг»)**, а не попутный вывод в патче по первой главе.

## План (не сделано)

1. **Баг тегов:** перед Qwen `<|pause|>` → `\n\n`, остальные теги вырезать; в промпте эмоций теги и `instruct_prompt` не генерировать.
2. **Кастинг** — отдельный этап после анализа персонажей, на всю книгу:
   - вход: последнее описание, пол, возраст из текста, 3–5 реплик из сценария, весь состав (чтобы развести похожих);
   - выход — структура, без эмоций: `gender`, `age` числом, `age_impression`, `pitch`, `texture`, `pace`, `manner`, `avoid`;
   - промпт VoiceDesign собирается шаблоном с точным возрастом и диапазоном (как в README: «Male, 17 years old, tenor range, …»);
   - образец — одна нейтральная фраза на 8–10 с, не реплика персонажа;
   - голос только тем, у кого есть реплики (не младенцу Линли);
   - проверка F0 (взрослая женщина > 280 Гц → перегенерация) + прослушивание автором;
   - результат: `storage/voices/<id>/reference.wav` + `reference.txt` + метаданные профиля → автоподбор по полу/возрасту, последнее слово за человеком в UI.
3. **Высота женских голосов** — эксперименты: «alto, low-pitched, mature» вместо возраста; instruct на китайском (как в README); дизайн на английском, клонирование на русском.
4. **Постоянные изменения голоса** (повзрослел, травма) — вариант голоса с главы N в кастинге (`voice_timeline`). Временные (болен, шепот) на Qwen Base не выразить.
5. **Опционально:** честное сравнение с CosyVoice 3 (те же реплики и референс, CER через Whisper + слепое прослушивание) — скорее на GPU у друга.
6. Прослушать: `Маомао_v2.wav`, `Джинши_болен.wav`, `clone_tags.wav`, `pause_*.wav`.
