# BookWeaver AI Backend

**BookWeaver Backend** — это CLI-инструмент для автоматической конвертации текстовых книг в аудиоспектакли. Скрипт
анализирует текст, создает сценарий, синтезирует голоса и генерирует портреты персонажей.

> [!IMPORTANT]
> В данный момент проект работает через консольный интерфейс (CLI). REST API находится в процессе переработки. Активная
> доработка планируется где-то в Июле.

## Функциональность

### AI Пайплайны

* **Summary Generation:** Генерирует краткие содержания (тизеры и синопсисы) глав для сохранения контекста при обработке
  длинных текстов.

* **Character Analysis:** Сканирует книгу, выявляет персонажей, определяет их пол, внешность и роль. Отслеживает
  изменения возраста или голоса по ходу сюжета.

* **Scenario Generation:** Преобразует исходный текст в формат сценария:
    * Разделяет прямую речь и слова автора.
    * Назначает спикера для каждой реплики.
    * Добавляет теги эмоций.
    * Подбирает фоновые звуки (эмбиент) и эффекты (SFX).

### Аудио

* **CosyVoice:** Интеграция с моделью CosyVoice для клонирования голосов и синтеза речи с поддержкой эмоций.

* **Stable Whisper:** Выравнивание аудио и текста для генерации субтитров (пословные таймкоды).

### Визуализация

* **ComfyUI:** Автоматическая генерация портретов персонажей на основе их текстового описания.

## Технический стек

* **Core:** Python 3.10+

* **LLM:** **Google Gemini** или **OpenRouter** (рекомендуется).

* **TTS:** CosyVoice (внешний сервис).

* **Image Gen:** ComfyUI (внешний сервис).

* **Audio:** FFmpeg, SoundFile.

## Установка

### 1. Предварительные требования

* **NVIDIA GPU** (для локального запуска CosyVoice и ComfyUI).

* **Docker Desktop** (рекомендуется для запуска CosyVoice).

* **FFmpeg** (должен быть доступен в системном PATH).

> [!NOTE]
> Хотя генерация картинок очень ресурсоемкая, и CosyVoice тоже много жрет, проект все равно можно запустить на CPU

### 2. Клонирование и окружение

```bash
git clone [https://github.com/lapcevichme/bookweaverbackend](https://github.com/lapcevichme/bookweaverbackend)
cd backend

# Создание venv
python -m venv venv

# Активация (Windows)
venv\Scripts\activate
# Активация (Linux/Mac)
source venv/bin/activate

# Установка зависимостей, ~3GB
pip install -r requirements.txt
```

### 3. Конфигурация (.env)

В корне проекта есть шаблон `.env.example`. Создайте на его основе файл `.env`:

**Windows:**

```powershell
copy .env.example .env
```

**Linux/Mac:**

```bash
cp .env.example .env
```

**Основные переменные:**

| Переменная             | Описание                                                                |
|:-----------------------|:------------------------------------------------------------------------|
| `LLM_PROVIDER`         | `google` (по умолчанию) или `openrouter`. **Рекомендуется OpenRouter.** |
| `GOOGLE_API_KEY`       | Ключ Google AI Studio (если выбран провайдер `google`).                 |
| `OPENROUTER_API_KEY`   | Ключ OpenRouter (если выбран провайдер `openrouter`).                   |
| `FAST_MODEL_NAME`      | Модель для простых задач - лучше какие-то flash или дешевые             |
| `POWERFUL_MODEL_NAME`  | Модель для сложных задач                                                |
| `COSYVOICE_API_URL`    | Адрес API CosyVoice. По умолчанию: `http://localhost:9233`.             |
| `COMFY_SERVER_ADDRESS` | Адрес API ComfyUI. По умолчанию: `http://127.0.0.1:8188`.               |

> [!TIP]
> Рекомендуется использовать **OpenRouter** для доступа к бесплатным моделям, которые хорошо справляются
> с задачами сценариста. Мои личные фавориты Qwen 3.5 Flash и Xiaomi Mimo V2 Flash.

> [!WARNING]
> Если генерация занимает очень долго, в консоли видно, что используется много токенов, но текст на выходе очень
> маленький, проверьте другие модели. Есть шанс, что выбранная имеет проблемы со стоп-токеном, такое было у Step-3.5

### 4. Настройка внешних сервисов

Для работы требуются два внешних сервиса (можно запустить локально или на удаленном сервере).

#### A. CosyVoice (TTS)

Рекомендуемый способ запуска — через **Docker**.

1. Найдите и скачайте Docker-образ с API-оберткой для CosyVoice (например, `cosyvoice-api`).
2. Запустите контейнер, пробросив порт (стандартный: `9233`).
3. Проверьте доступность API по адресу из `COSYVOICE_API_URL`.

> [!NOTE]
> Пакет с CosyVoice3 есть в Docker Desktop (где-то)

#### B. ComfyUI (Иллюстрации)

Можно использовать Docker или **Portable версию** (для Windows).

1. **Установка:** Скачайте ComfyUI.
2. **Запуск:** Запустите `run_nvidia_gpu.bat` (или аналог).
3. **Workflow:**
    * В папке `assets/` находится файл `comfy_workflow.json`.
    * Приложение отправляет этот workflow в ComfyUI через API.
    * **Важно:** Убедитесь, что в ComfyUI установлены все необходимые модели (Checkpoints, Loras), используемые в
      workflow.

> [!CAUTION]
> При установке может возникнуть что угодно - обновили сервис, какие-то проблемы с системой и тд. Ищите туториал на
> ComfyUI, там интересно и сложно.

## Использование (CLI)

Взаимодействие с программой происходит через скрипт `cli.py`.

```bash
python cli.py
```

### Режимы работы:

1. **Импорт книги:**
    * Укажите путь к файлу (`.zip` или `.epub`).
    * Книга будет скопирована в `input/books/` и подготовлена к работе.

2. **Полный цикл (Auto-Pilot):**
    * Последовательный запуск всех этапов: Саммари -> Персонажи -> Иллюстрации -> Сценарий -> Озвучка.

3. **Ручное управление:**
    * Запуск отдельных этапов (например, только генерация сценария или только TTS) для отладки или частичного
      обновления.

## Структура проекта

```text
backend/
├── .env.example         # Шаблон конфигурации
├── cli.py               # Интерфейс командной строки
├── main.py              # Основной класс-оркестратор
├── pipelines/           # Модули обработки (Summary, Character, Scenario, TTS, Image)
├── services/            # Клиенты API (LLM, CosyVoice, ComfyUI)
├── core/                # Модели данных (Pydantic)
├── assets/              # Ресурсы (звуки, промпты, workflow)
├── input/               # Папка с исходными книгами
└── output/              # Результаты генерации
```

### Размышления

На OpenRouter добавили Image и Audio модели. Можно попробовать добавить для этого Api поддержку. Но наверное это будет
очень дорого.

Есть отличная альтернатива Whisper от Китайцев, нужно обязательно встроить ее в проект, как только будет момент

CLI Интерфейс мне в целом нравится, но объективно лучше сделать какой-нибудь веб интерфейс. Если будет желание
позаниматься диким вайбкодом, то будет выполнено. Ну или же попросить какого-то человечка, который очень хочет
поработать над проектом такого формата.

По поводу голосов - наверное лучше сделать нормальную интеграцию с 11labs и не париться с дикими парсерами аудио. Либо
найти очень хорошую библиотеку голосов, но я не смог.
